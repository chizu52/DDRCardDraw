### Folder and Assests are focused for DLD2. YMMV when changing any assets, fonts, or images.

## Fonts
- Folder is not included for licensing reasons. You must supply your own font files. Folder must be named "fonts" for the styling to import properly.
  - "title-font.otf" for all title text
  - "body-font.otf" for all body text

## Icons
- I strongly suggest just using the custom choice from the Icon's dropdown list, however if you must keep it in the assets folder: 
  - File names are imported exactly as named, capitalization matters.

## Schedule
- Any 1600x600 .png file will fill the background for the Schedule.
  - Must be named "bg.png" for the OBS source to pick it up.
